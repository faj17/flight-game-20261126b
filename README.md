Kestrel Courier — fly a courier plane across a valley, through golden rings and onto the runway. Three missions, one valley, fuel and damage that turn every sortie into decisions.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network request, desktop Chrome.

Controls: Arrows / WASD pitch and bank · Shift / Ctrl throttle · mouse steer (hold left button) · C chase / cockpit camera · P pause · R restart. Pick a mission with 1, 2 or 3.
